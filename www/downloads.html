Run iuna

The new Heartbeat and Ledger protocol currently ships as a source-only development preview.

Candidate mainnet: this is not mainnet yet, and the protocol remains experimental. The chain is intended to carry forward if the candidate is promoted, so coins will probably remain valid, but that is not guaranteed.

Build from source

Install a current Rust toolchain, clone the repository, and run the IUNA node.

git clone https://github.com/iuna-labs/iuna.git
cd iuna
cargo run --release
Public peer safety: expose only the P2P listener on TCP port 9444. Keep the operator HTTP interface on loopback; management endpoints refuse non-loopback binding.

Not sure how to participate? Read the getting started guide.
